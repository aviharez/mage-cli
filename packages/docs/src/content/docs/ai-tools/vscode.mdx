title: VS Code Integration

---

Mage runs in your terminal and works alongside any editor. Here's how to get the best experience with VS Code.

## Running in VS Code Terminal

Open the integrated terminal in VS Code (`Ctrl+\``) and run:

```bash
mage
```

Mage will automatically detect your project root based on the current directory.

## Web UI Workflow

For a richer interface, use the web UI alongside VS Code:

1. Start the Mage server: `mage serve --port 4096`
2. Open `http://localhost:4096` in your browser
3. Keep your editor and Mage web UI side by side

## Tips

- Run `mage` in the project root so it can access all your files
- Use the file tree view in the Mage web UI to navigate your codebase
- Copy code snippets from Mage directly into VS Code
