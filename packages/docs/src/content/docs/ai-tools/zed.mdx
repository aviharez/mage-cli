Mage includes a Zed editor extension that registers it as an agent server, enabling deep integration with the Zed editor.

## Installing the Extension

The Mage Zed extension is located in `packages/extensions/zed/`. To install it:

1. Open Zed
2. Go to Extensions (`Cmd+Shift+X`)
3. Install from local path and point to `packages/extensions/zed/`

Or install from the extension registry once published.

## Using Mage in Zed

Once installed, Mage appears in Zed's agent panel. It communicates via the ACP (Agent Communication Protocol) using:

```bash
mage acp
```

The extension automatically downloads the appropriate Mage binary for your platform.

## Supported Platforms

- macOS (Apple Silicon & Intel)
- Linux (x64 & ARM64)
- Windows (x64)
