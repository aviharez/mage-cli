## 1. Install Mage

```bash
npm install -g @mybcabisnis/mage
```

## 2. Navigate to your project

```bash
cd /your/project
```

## 3. Start Mage

```bash
mage
```

This opens the interactive TUI. You can start chatting with the AI immediately.

## Basic Commands

| Command | Description |
|---------|-------------|
| `mage` | Start the terminal UI |
| `mage serve` | Start the web server (default port 4096) |
| `mage --help` | Show all available commands |

## First Conversation

Once Mage is running, you can:

- **Ask about your codebase**: "Explain the architecture of this project"
- **Write code**: "Add a new endpoint to the Express router in src/routes.ts"
- **Fix bugs**: "There's a null pointer error in the auth middleware, help me fix it"
- **Refactor**: "Refactor this function to use async/await instead of callbacks"

## Web UI

Mage includes a built-in web interface. Start the server and open your browser:

```bash
mage serve --port 4096
# Open http://localhost:4096
```
