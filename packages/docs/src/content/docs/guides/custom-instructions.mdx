title: Custom Instructions
description: Customize Mage's behavior with AGENTS.md and project instructions
---

## AGENTS.md

Create an `AGENTS.md` file in your project root to give Mage context about your project:

```markdown
# Project Context

This is a Spring Boot application using Java 17.
The database is PostgreSQL with Flyway migrations.

## Coding Standards
- Use constructor injection over field injection
- All new endpoints must have unit tests
- Follow the existing package structure

## Important Files
- `src/main/resources/application.yml` — App configuration
- `src/test/java/` — Test directory
```

Mage reads this file at startup and incorporates the instructions into every conversation.

## Global Instructions

Set global instructions that apply to all projects:

```json
{
  "instructions": "Always include JSDoc comments on public functions. Prefer TypeScript strict mode."
}
```

## Per-Session Instructions

You can also provide instructions at the start of a session by typing them as your first message:

```
For this session, focus on performance optimizations. Don't refactor code unless I explicitly ask.
```

## Tips

- Keep `AGENTS.md` files focused and concise
- Include information about tech stack, coding conventions, and key files
- Update `AGENTS.md` as your project evolves
- Use the global config for preferences that apply everywhere
