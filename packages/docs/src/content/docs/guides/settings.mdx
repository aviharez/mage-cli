---

Mage is configured via a JSON file at `~/.config/mage/config.json` (or `$MAGE_CONFIG_DIR/config.json`).

## Configuration File

```json
{
  "provider": {
    "merlin": {
      "endpoint": "https://your-merlin-endpoint.bca.co.id",
      "apiKey": "your-api-key"
    }
  },
  "model": {
    "default": "merlin/gaia"
  },
  "theme": "dark"
}
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `MAGE_CONFIG_DIR` | Override config directory location |
| `MAGE_DISABLE_SHARE` | Disable session sharing feature |

## Theme

Mage supports multiple themes. Set the `theme` field in your config:

- `dark` (default)
- `light`
- `system`

## Model Selection

By default, Mage uses the GAIA model via the internal Merlin provider. You can configure alternative providers if available:

```json
{
  "model": {
    "default": "merlin/gaia",
    "fallback": "anthropic/claude-3-7-sonnet-latest"
  }
}
```

## System Prompt (Custom Instructions)

Add custom instructions to guide the AI's behavior:

```json
{
  "instructions": "Always write TypeScript. Prefer functional programming patterns. Use Effect for error handling."
}
```
