## Prerequisites

- Node.js 18 or higher (for the npm install path)
- Access to BCA internal npm registry (`https://artifactory.intra.bca.co.id/artifactory/api/npm/MBB-Registry-npm/`)

## Install from BCA Registry

Configure your `.npmrc` to point to the BCA registry, then install:

```bash
npm install -g @mybcabisnis/mage
```

Or with bun:

```bash
bun install -g @mybcabisnis/mage
```

## Install from Source

Clone the repository and build:

```bash
git clone https://github.com/anomalyco/opencode
cd mage
bun install
bun run build:mage
```

## Verify Installation

```bash
mage --version
```

## Running Mage

Start the TUI (terminal UI):

```bash
mage
```

Start the web server (accessible at `http://localhost:4096`):

```bash
mage serve --port 4096
```

Or use the dev shortcut which also loads default config:

```bash
# From the project root
bun dev:serve
```
