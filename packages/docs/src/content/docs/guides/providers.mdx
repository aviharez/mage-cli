title: Providers & Models
description: Configure AI providers and select models
---

Mage supports multiple AI providers. The default and primary provider is BCA's internal **Merlin/GAIA**.

## BCA Merlin (Default)

The built-in Merlin provider connects to BCA's internal GAIA model. This is the recommended provider for BCA developers.

```json
{
  "provider": {
    "merlin": {
      "endpoint": "https://your-merlin-endpoint.bca.co.id"
    }
  }
}
```

No API key is required if you are on the BCA internal network (authentication is handled via SSO).

## Other Providers

Mage also supports external providers for development and testing purposes:

| Provider | Config Key |
|----------|------------|
| Anthropic | `anthropic` |
| OpenAI | `openai` |
| Google Gemini | `google` |
| Amazon Bedrock | `amazon-bedrock` |
| Azure OpenAI | `azure` |
| Groq | `groq` |

Example with Anthropic:

```json
{
  "provider": {
    "anthropic": {
      "apiKey": "sk-ant-..."
    }
  },
  "model": {
    "default": "anthropic/claude-3-7-sonnet-latest"
  }
}
```

## Model Naming

Models are referenced as `provider/model-id`:

- `merlin/gaia` — BCA GAIA model
- `anthropic/claude-3-7-sonnet-latest` — Anthropic Claude
- `openai/gpt-4o` — OpenAI GPT-4o
- `google/gemini-2.5-flash` — Google Gemini Flash

## Environment Variables

For providers that require API keys, you can also set them via environment variables:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export OPENAI_API_KEY=sk-...
```
