## What is Mage?

Mage is an AI-powered coding assistant that runs in your terminal, powered by BCA's GAIA model. It helps you write, understand, and refactor code through natural language conversations.

<CardGrid stagger>
	<Card title="Terminal-first" icon="laptop">
		Runs entirely in your terminal. No browser required for core functionality.
	</Card>
	<Card title="Powered by GAIA" icon="star">
		Uses BCA's internal Merlin/GAIA AI models for intelligent code assistance.
	</Card>
	<Card title="Web UI included" icon="document">
		Includes a built-in web interface accessible at `localhost:4096`.
	</Card>
	<Card title="Desktop app" icon="setting">
		Available as an Electron desktop application for macOS, Windows, and Linux.
	</Card>
</CardGrid>
