---
title: Building the Desktop App
description: Build and package Mage Desktop for distribution
---

## Prerequisites

- Bun 1.3.14+
- Node.js 18+ (for electron-builder)
- Platform-specific build tools (Xcode on macOS, Visual C++ on Windows)

## Development

Start the desktop app in development mode:

```bash
# From the monorepo root
bun dev:desktop

# Or from the desktop package
cd packages/desktop
bun dev
```

This starts Electron with hot-reload. The `predev` script automatically builds the Mage server bundle first.

## Building for Production

```bash
cd packages/desktop
bun build
```

This runs `electron-vite build` which produces output in `packages/desktop/out/`.

## Packaging

Package for your current platform:

```bash
cd packages/desktop
bun package
```

Platform-specific:

```bash
bun package:mac    # macOS .dmg + .zip
bun package:win    # Windows NSIS installer
bun package:linux  # AppImage, .deb, .rpm
```

## Channel Configuration

Set the build channel before packaging:

```bash
MAGE_CHANNEL=beta bun package:mac
```

Available channels: `dev`, `beta`, `prod`

## Native Modules

The desktop app includes native modules (node-pty for terminal emulation). Build them with:

```bash
cd packages/desktop
bun native:build
```

## Outputs

After packaging, distributables are in `packages/desktop/dist/`:

- macOS: `Mage-1.1.0-arm64.dmg`, `Mage-1.1.0-arm64-mac.zip`
- Windows: `Mage Setup 1.1.0.exe`
- Linux: `Mage-1.1.0.AppImage`, `mage_1.1.0_amd64.deb`
