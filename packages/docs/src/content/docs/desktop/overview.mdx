Mage Desktop is an Electron-based native application that wraps the Mage web UI in a dedicated window with native OS integration.

## Features

- **Native window** with proper title bar and menus
- **Deep link support** via the `mage://` protocol
- **Auto-updater** for seamless version upgrades
- **System tray** integration
- **Native menus** (File, Edit, View, Go, Window, Help)
- **Multi-language UI** (English, Japanese, Korean, Chinese, and more)
- **Cross-platform**: macOS, Windows, Linux

## Architecture

The desktop app embeds the Mage server as a sidecar process. When you launch the desktop app:

1. Electron starts and initializes the renderer process
2. A local Mage server is spawned on a random port
3. The Electron window connects to the local server
4. All AI requests go through the bundled Mage backend

This means **no separate `mage serve` command is needed** when using the desktop app.

## Security

Communication between the renderer and the sidecar uses:
- Localhost-only binding (not exposed to the network)
- Random UUID password for authentication
- CORS restricted to the Electron renderer
