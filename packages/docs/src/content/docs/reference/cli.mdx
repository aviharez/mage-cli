## Synopsis

```
mage [command] [options]
```

## Commands

### `mage` (default)

Start the interactive terminal UI.

```bash
mage [--cwd <directory>]
```

### `mage serve`

Start the HTTP server with the web UI.

```bash
mage serve [--port <port>]
```

**Options:**
- `--port` — Port to listen on (default: `4096`)

### `mage acp`

Start in Agent Communication Protocol mode (for IDE integrations).

```bash
mage acp
```

### `mage auth`

Manage authentication for AI providers.

```bash
mage auth login [provider]
mage auth logout [provider]
mage auth list
```

## Global Options

| Option | Description |
|--------|-------------|
| `--help` | Show help |
| `--version` | Show version number |
| `--cwd <path>` | Set working directory |

## Environment Variables

| Variable | Description |
|----------|-------------|
| `MAGE_CONFIG_DIR` | Config directory (default: `~/.config/mage`) |
| `MAGE_DISABLE_SHARE` | Disable session sharing |
| `MAGE_SERVER_USERNAME` | Server auth username |
| `MAGE_SERVER_PASSWORD` | Server auth password |
