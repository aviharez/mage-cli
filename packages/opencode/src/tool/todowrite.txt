Use this tool to create and manage a structured task list for your current coding session. It tracks progress on complex work and shows the user what's happening.

## When to use
- The task requires 3+ distinct steps or non-trivial planning
- The user explicitly requests a todo list, or supplies multiple tasks (numbered/comma-separated)
- Immediately after receiving new instructions, capture requirements as todos; revise as you learn more
- Mark a task complete the moment it's finished, then move to the next

## When NOT to use
- A single, straightforward, or trivial task (e.g. answering a question, one-line edit, running one command)
- Fewer than 3 steps with no organizational benefit

## Task states and management
- **pending**: not started
- **in_progress**: currently working on it — only ONE at a time
- **completed**: finished successfully
- **cancelled**: no longer needed

Update status in real time; mark tasks complete immediately rather than batching; complete the current task before starting the next; cancel tasks that become irrelevant. Break complex work into specific, actionable items with clear names.
