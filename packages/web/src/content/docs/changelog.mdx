## v0.4.2

_Juni 2026_

### Yang baru
- **Skill `verify`** — Perintah baru untuk memverifikasi perubahan kode berjalan sesuai ekspektasi.
- **Guard satu subagent** — Task sekarang dijaga agar hanya menjalankan satu subagent dalam satu waktu untuk mencegah konflik.
- **Skill Angular & MBB-lib** — Skill angular-developer sekarang terhubung dengan skill mbb-lib.
- Boilerplate info disembunyikan dari sidebar jika tidak tersedia.

### Perbaikan
- Perbaikan styling hub page dan navigasi halaman detail.
- Perbaikan bundling shim `zod`/`yaml` agar plugin boilerplate dapat dimuat di aplikasi desktop.
- Hapus file yang tidak digunakan.

_Mei 2026_

## v0.3.x

_April 2026_

Versi awal fork dari OpenCode dengan integrasi provider Merlin/GAIA BCA. Fitur utama:
- Koneksi ke gateway GAIA internal via provider `merlin`.
- Autentikasi menggunakan username udomain BCA.
- Dukungan boilerplate tim dengan injeksi konvensi otomatis.
- Slash commands: `/generate`, `/test`, `/review`, `/boilerplate`.
- Review MR GitLab via binary `mr-reviewer`.
