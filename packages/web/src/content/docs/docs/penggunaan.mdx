## Subcommand

| Perintah | Deskripsi |
|----------|-----------|
| `mage` | Buka TUI interaktif di direktori saat ini |
| `mage run "pesan"` | Kirim satu pesan tanpa membuka TUI |
| `mage init` | Jalankan ulang wizard konfigurasi |
| `mage providers` | Kelola kredensial provider |
| `mage models` | Tampilkan daftar model yang tersedia |
| `mage serve` | Jalankan server headless (tanpa membuka browser) |
| `mage web` | Jalankan server dan buka antarmuka web di browser |

## TUI Interaktif

Jalankan `mage` dari direktori proyek untuk membuka sesi interaktif:

```bash
cd ~/code/myproject
mage
```

Mage akan mengindeks file di repository Anda sebelum sesi dimulai.

### Shortcut keyboard

| Shortcut | Aksi |
|----------|------|
| `?` | Tampilkan daftar shortcut lengkap |
| `Ctrl+C` | Interrupt — hentikan aksi agent yang sedang berjalan |
| `Ctrl+D` | Keluar dari TUI |

Ketik `/` untuk membuka autocomplete slash command. Lihat [Slash Commands](/docs/slash-commands) untuk daftar lengkap.

## Mengirim satu pesan (tanpa TUI)

Gunakan `mage run` untuk otomasi atau skrip:

```bash
mage run "Jelaskan fungsi getUserById di file src/user.ts"
```

Output dicetak ke stdout dan Mage keluar setelah selesai.

## Informasi model

Model yang digunakan adalah **`merlin/default`** via gateway GAIA BCA.

```bash
mage models
```

## Versi Web

Mage memiliki antarmuka browser yang lengkap — tampilan yang lebih kaya dari TUI dengan chat, file tree, diff, dan terminal tertanam.

### Membuka versi web

```bash
mage web
```

Perintah ini menjalankan server Mage dan **secara otomatis membuka browser** ke URL lokal. Port ditentukan otomatis oleh sistem (atau bisa diatur manual):

```bash
mage web --port 8080
```

### Menjalankan server tanpa browser

```bash
mage serve
```

Gunakan ini jika Anda ingin server berjalan di latar belakang tanpa membuka browser. Server akan mencetak URL-nya di terminal.

### Fitur yang tersedia

- **Chat sesi** — percakapan penuh dengan agent, sama seperti TUI
- **File tree & diff** — tampilan visual perubahan file yang dibuat agent
- **Terminal tertanam** — jalankan perintah shell langsung dari browser
- **Pengaturan** — model, provider, keybinding

### Sesi yang sama dengan TUI

Versi web dan TUI terhubung ke **server yang sama**. Sesi yang dibuat di TUI terlihat di versi web, dan sebaliknya — selama keduanya menunjuk ke server yang sama.

:::note[Akses jaringan]
Secara default server hanya bisa diakses dari localhost. Jika perlu akses dari perangkat lain di jaringan yang sama, jalankan `mage web --host 0.0.0.0`.
:::
