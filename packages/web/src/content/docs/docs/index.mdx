**Mage** adalah asisten coding AI berbasis terminal yang terhubung ke **GAIA**. Workflow yang sama, namun lebih dekat dengan project Anda.

## Prasyarat

Node.js **≥ 18** harus sudah terinstal. Unduh di Software Center.

## Instalasi cepat

<Tabs>
  <TabItem label="Windows PowerShell">
    ```powershell
    irm https://mybcabisnis-mage.apps.ocpdevgra.dti.co.id/install.ps1 | iex
    ```
  </TabItem>
  <TabItem label="macOS / Linux">
    ```bash
    curl -fsSL https://mybcabisnis-mage.apps.ocpdevgra.dti.co.id/install | bash
    ```
  </TabItem>
</Tabs>

Installer mengonfigurasi `C:\Users\udomain\.npmrc` untuk BCA Artifactory secara otomatis, lalu menginstal `@mybcabisnis/mage` secara global.

Untuk opsi instalasi lengkap (Windows cmd, manual `.npmrc`, dari source), lihat [Instalasi](/docs/instalasi).

## Setup pertama

Jalankan `mage` untuk pertama kalinya. Wizard setup akan muncul otomatis dan meminta **username udomain BCA** Anda (format `u0…`):

```
$ mage

  █▄ ▄█ ▄▀▀▄ █▀▀▀ █▀▀▀
  █ ▀ █ ████ █ ▄█ █▀▀▀
  ▀   ▀ ▀  ▀ ▀▀▀▀ ▀▀▀▀

◆ Mage setup
│
◆ BCA udomain username
│  u0xxxxx
└  Config saved → ~/.mage/mage.json
```

Wizard hanya berjalan sekali. Jalankan `mage init` kapan saja untuk mengulang konfigurasi.

## Buka sesi

`cd` ke direktori proyek dan jalankan `mage`:

```bash
cd ~/code/myproject
mage
```
