**Mage** adalah asisten coding AI berbasis terminal yang terhubung ke **GAIA** — gateway LLM internal BCA. Mage adalah fork dari [OpenCode](https://opencode.ai) yang disesuaikan untuk infrastruktur BCA: tanpa API key pribadi, dengan log audit bawaan.

## Prasyarat

Node.js **≥ 18** harus sudah terinstal. Unduh di [nodejs.org](https://nodejs.org/en/download).

## Instalasi cepat

<Tabs>
  <TabItem label="macOS / Linux">
    ```bash
    curl -fsSL https://mage.apps.ocpdevgra.dti.co.id/install | bash
    ```
  </TabItem>
  <TabItem label="Windows PowerShell">
    ```powershell
    irm https://mage.apps.ocpdevgra.dti.co.id/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

Installer mengonfigurasi `~/.npmrc` untuk BCA Artifactory secara otomatis, lalu menginstal `@mybcabisnis/mage` secara global.

Untuk opsi instalasi lengkap (Windows cmd, manual `.npmrc`, dari source), lihat [Instalasi](/docs/instalasi).

## Setup pertama

Jalankan `mage` untuk pertama kalinya. Wizard setup akan muncul otomatis dan meminta **username udomain BCA** Anda (format `u0…`):

```
$ mage

  █▄ ▄█ ▄▀▀▄ █▀▀▀ █▀▀▀
  █ ▀ █ ████ █  █ █▀▀▀
  ▀   ▀ ▀  ▀ ▀▀▀▀ ▀▀▀▀

◆ Mage setup
│
◆ BCA udomain username
│  u0johndoe
└  Config saved → ~/.mage/mage.json
```

Wizard hanya berjalan sekali. Jalankan `mage init` kapan saja untuk mengulang konfigurasi.

## Buka sesi

`cd` ke direktori proyek dan jalankan `mage`:

```bash
cd ~/code/myproject
mage
```

Mage mengindeks repository Anda dan membuka TUI. Di dalam TUI:

| Shortcut | Aksi |
|----------|------|
| `?` | Tampilkan daftar shortcut |
| `Ctrl+C` | Interrupt agent |
| `Ctrl+D` | Keluar |
