**Skill** adalah instruksi dan alur kerja khusus yang dimuat model secara otomatis ketika prompt Anda cocok dengan deskripsi skill tersebut. Tidak ada perintah khusus yang perlu diingat — cukup tuliskan apa yang ingin Anda lakukan dalam bahasa natural.

---

## Cara memicu skill

Tulis prompt natural yang mendeskripsikan tugas Anda. Model akan mencocokkan prompt dengan deskripsi skill yang tersedia dan memuat skill yang relevan sebelum mulai mengerjakan.

### Contoh trigger (English & Indonesia)

| Skill | Contoh prompt (EN) | Contoh prompt (ID) |
|-------|-------------------|-------------------|
| **angular-developer** | "Migrate this project to Angular standalone components" | "Migrasikan project ini ke Angular standalone components" |
| **mbb-lib** | "Build a login form using the MBB component library" | "Buat form login menggunakan library komponen MBB" |
| **functional-flow** | "Generate a functional flow diagram for this project" | "Buat diagram functional flow untuk project ini" |
| **readme** | "Generate a README for this project" | "Buatkan README untuk project ini" |
| **verify** | "Verify that the payment feature works correctly" | "Verifikasi bahwa fitur pembayaran berjalan dengan benar" |
| **code-review-and-quality** | "Review this code before I commit it" | "Review kode ini sebelum saya commit" |

:::tip[Browse skill secara manual]
Ketikkan `/skills` di TUI untuk membuka dialog browser skill — Anda bisa melihat semua skill yang tersedia dan mengaktifkannya secara manual jika diperlukan.
:::

## Skill bawaan

Mage menyertakan **25 skill bawaan**. Berikut beberapa yang paling relevan untuk penggunaan sehari-hari:

| Skill | Kegunaan |
|-------|----------|
| **angular-developer** | Generate kode Angular, migrasi standalone, signals, control flow |
| **mbb-lib** | Gunakan library komponen MBB (`@mybcabisnis-web/lib`) di proyek Angular |
| **functional-flow** | Buat dokumen Functional Flow (diagram Mermaid, API endpoints) |
| **readme** | Generate atau update README proyek secara otomatis |
| **verify** | Verifikasi perubahan kode berjalan sesuai ekspektasi |
| **code-review-and-quality** | Review kode multi-dimensi sebelum merge |
| **code-simplification** | Sederhanakan kode yang terlalu kompleks tanpa mengubah behavior |
| **test-driven-development** | Tulis test lebih dulu, lalu implementasi |
| **debugging-and-error-recovery** | Analisis root cause dari bug, error, atau test yang gagal |
| **planning-and-task-breakdown** | Pecah spesifikasi menjadi task yang dapat diimplementasikan |

Seluruh 25 skill tersedia saat Anda menginstal Mage. Skill lain yang tersedia mencakup: `api-and-interface-design`, `ci-cd-and-automation`, `context-engineering`, `deprecation-and-migration`, `documentation-and-adrs`, `doubt-driven-development`, `frontend-ui-engineering`, `git-workflow-and-versioning`, `idea-refine`, `incremental-implementation`, `interview-me`, `performance-optimization`, `security-and-hardening`, `shipping-and-launch`, `source-driven-development`, `spec-driven-development`, dan lainnya.

## Membuat skill kustom

Anda bisa menambahkan skill sendiri untuk workflow atau konvensi tim yang spesifik.

### Lokasi

| Scope | Path |
|-------|------|
| Global (berlaku di semua proyek) | `~/.mage/skills/<nama-skill>/SKILL.md` |
| Per-proyek | `<direktori-proyek>/.mage/skills/<nama-skill>/SKILL.md` |

### Format `SKILL.md`

Hanya dua field yang wajib ada: `name` dan `description`.

```markdown
---
name: your-skill-name
description: >
  What this skill does. Use/Activate when the user asks for X, Y,
  or Z. The more specific the trigger description, the more accurately
  the model detects when to load this skill.
---

# Skill Title

## Overview
Short explanation of what this skill does.

## When to Use
- When the user asks for ...
- When the project uses ...

## Workflow
### Step 1 — ...
### Step 2 — ...

## Verification
- [ ] Check this
- [ ] Check that
```

:::tip[Menulis deskripsi yang baik]
Field `description` adalah satu-satunya yang digunakan model untuk menentukan kapan skill ini cocok. Tulis secara eksplisit kondisi pemicunya: "Gunakan ketika pengguna meminta membuat/mengubah X" atau "Aktifkan sebelum membuat komponen Y". Deskripsi yang samar menghasilkan trigger yang tidak akurat.
:::

### Contoh skill minimal

````markdown
---
name: spring-boot-service
description: >
  Generate or modify Spring Boot service classes following BCA
  backend team conventions. Use when the user asks to create a
  service, repository, or controller.
---

# Spring Boot Service Generator

Follow these conventions when creating a Spring Boot service:

1. Use the `@Service` annotation
2. Inject dependencies via constructor (not field injection)
3. Method names follow the `verbNoun` pattern (e.g. `getUserById`)
4. All errors thrown as `BusinessException` with an error code

## Package structure
```
id.co.bca.app/
├── service/        ← put service classes here
├── repository/
└── controller/
```
````

### File pendukung

Anda bisa menyertakan file pendukung (referensi, contoh kode, template) di dalam direktori skill yang sama. Jalur relatif dalam `SKILL.md` akan diresolvasi terhadap direktori skill tersebut.

```
~/.mage/skills/spring-boot-service/
├── SKILL.md
├── references/
│   └── service-template.java
└── examples/
    └── ExampleUserService.java
```

Mage akan mengekspos file-file ini ke model saat skill dimuat, sehingga model bisa menggunakannya sebagai referensi.
