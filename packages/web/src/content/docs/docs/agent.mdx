**Agent** adalah persona bernama yang menentukan sistem prompt, izin tool, dan model yang digunakan model selama sesi berlangsung. Mage menyertakan beberapa agent bawaan — dua di antaranya dapat Anda pilih langsung dari TUI, sementara lainnya bekerja di balik layar sebagai **subagent** yang didelegasikan secara otomatis.

---

## Agent bawaan

Mage dilengkapi dua **primary agent** yang dapat Anda aktifkan langsung dari TUI:

| Agent | Kegunaan |
|-------|----------|
| **Forge** | Agent eksekusi (default) — menjalankan tool sesuai permission yang dikonfigurasi. Digunakan untuk mengerjakan tugas: menulis kode, mengedit file, menjalankan perintah. |
| **Oracle** | Mode perencanaan — semua tool edit dinonaktifkan. Oracle hanya boleh menulis file rencana di `.mage/plans/*.md`. Gunakan untuk menyusun rencana sebelum eksekusi. |

### Alur plan → eksekusi dengan Oracle dan Forge

Oracle dan Forge dirancang untuk bekerja berpasangan:

1. Pindah ke **Oracle** → minta model menyusun rencana. Oracle mempersiapkan file `.mage/plans/*.md` tanpa menyentuh kode.
2. Tinjau rencana yang dihasilkan — perbaiki jika perlu.
3. Pindah kembali ke **Forge** → Mage secara otomatis meminta Forge untuk mengeksekusi rencana yang sudah dibuat.

Pola ini berguna pada tugas besar yang memerlukan eksplorasi dan persetujuan sebelum perubahan kode dijalankan.

## Berpindah antar agent

Anda dapat berpindah agent kapan saja dari dalam TUI:

| Aksi | Shortcut / perintah |
|------|---------------------|
| Agent berikutnya | `Tab` |
| Agent sebelumnya | `Shift+Tab` |
| Buka dialog pemilih agent | `Ctrl+x` lalu `a` |
| Buka dialog pemilih agent | `/agents` |

:::tip[Agent aktif ditampilkan di status bar]
Nama agent aktif (misalnya **forge** atau **oracle**) ditampilkan di status bar bagian bawah TUI. Anda dapat mengubah default-nya dengan mengatur `default_agent` di file konfigurasi — lihat [Konfigurasi](/docs/konfigurasi).
:::

Lihat [Slash Commands](/docs/slash-commands) untuk daftar lengkap perintah yang tersedia di TUI.

## Subagent & delegasi

Selain primary agent, Mage memiliki **subagent** yang tidak bisa dipilih langsung dari TUI — mereka diaktifkan oleh model secara otomatis ketika tugas memerlukan bantuan khusus:

| Subagent | Kegunaan |
|----------|----------|
| **wisp** | Agen serbaguna untuk riset dan eksekusi multi-langkah. Cocok untuk menjalankan beberapa unit pekerjaan secara paralel. |
| **seeker** | Agen khusus eksplorasi kodebase yang hanya boleh membaca file. Mendukung tiga level ketuntasan: `quick`, `medium`, dan `very thorough`. |

Forge (dan Oracle) dapat mendelegasikan ke subagent melalui **Task tool** atau menyebut subagent secara langsung dengan `@nama-agent`. Anda dapat memandu model secara eksplisit:

```
@seeker cari semua komponen Angular yang menggunakan OnPush change detection, medium thoroughness
```

```
@wisp analisis ketiga modul ini secara paralel dan buat ringkasannya
```

:::note[Satu subagent dalam satu waktu]
Model hanya memanggil satu subagent per giliran. Setiap subagent mendapatkan konteks baru — berikan instruksi yang jelas: apakah subagent perlu riset saja, atau juga perlu menulis/mengubah kode.
:::

## Tips memaksimalkan agent

- **Oracle dulu, Forge kemudian.** Untuk tugas besar yang melibatkan banyak file atau risiko tinggi, pindah ke Oracle untuk merencanakan, tinjau hasilnya, lalu eksekusi dengan Forge.
- **Delegasikan pencarian ke seeker.** Kalau Anda perlu tahu di mana suatu fungsi didefinisikan atau menemukan pola tertentu di kodebase, minta seeker — lebih cepat dan lebih terfokus.
- **Gunakan wisp untuk pekerjaan paralel.** Bila ada beberapa modul independen yang perlu dianalisis sekaligus, wisp dapat menanganinya secara bersamaan.
- **Set `default_agent` di konfigurasi.** Jika Anda hampir selalu memulai sesi dengan Oracle, atur nilai ini agar Mage langsung masuk ke mode perencanaan — lihat [Konfigurasi](/docs/konfigurasi).
- **Sesuaikan model per-agent.** Agent kustom dapat mempunyai model dan permission tersendiri — lihat bagian *Membuat agent sendiri* di bawah.

## Membuat agent sendiri

Anda dapat menambahkan agent dengan sistem prompt, permission, dan model yang sepenuhnya kustom.

### Lokasi

| Scope | Path |
|-------|------|
| Global (semua proyek) | `~/.mage/agent/<nama-agent>.md` |
| Per-proyek | `.mage/agent/<nama-agent>.md` |

Nama file (tanpa ekstensi) menjadi **identifier agent** yang digunakan di TUI dan konfigurasi.

### Format file

**Isi markdown file menjadi system prompt** agent. Frontmatter YAML di bagian atas mengatur field konfigurasi:

```markdown
---
description: >
  Gunakan agent ini ketika pengguna meminta review kode Angular
  atau refaktor komponen menggunakan standalone API.
mode: subagent
model: merlin/default
temperature: 0.5
steps: 30
color: "#7C3AED"
---

Kamu adalah spesialis Angular di tim BCA. Ketika mereview kode:

1. Periksa apakah komponen menggunakan standalone API (Angular 17+)
2. Pastikan tidak ada NgModule yang masih dibuat manual
3. Cari potensi memory leak di subscription Observable
4. Berikan saran konkret dengan contoh kode
```

### Field yang tersedia

| Field | Tipe | Keterangan |
|-------|------|------------|
| `description` | string | Menjelaskan kapan agent ini cocok digunakan. Wajib ada agar model tahu kapan mendelegasikan ke sini. |
| `mode` | `primary` \| `subagent` \| `all` | `primary` = bisa dipilih di TUI; `subagent` = hanya via Task/`@`; `all` = keduanya. Default: `all`. |
| `model` | string | Provider/model yang digunakan (contoh: `merlin/default`). Mewarisi model sesi jika tidak diisi. |
| `temperature` | number | Nilai 0.0–1.0 untuk mengatur kreativitas respons. |
| `top_p` | number | Alternatif temperature untuk nucleus sampling. |
| `permission` | object | Aturan izin tool (apa yang boleh dijalankan). Lihat [Konfigurasi](/docs/konfigurasi). |
| `color` | string | Warna hex `#RRGGBB` atau nama tema (`primary`, `accent`, dll.) — tampil di TUI. |
| `steps` | integer | Jumlah maksimal iterasi agentic sebelum model dipaksa menjawab teks saja. |
| `hidden` | boolean | Sembunyikan dari autocomplete `@` (hanya berlaku untuk subagent). Default: `false`. |
| `disable` | boolean | Nonaktifkan agent ini, termasuk agent bawaan. |

### Alternatif: konfigurasi JSON

Agent juga bisa didefinisikan langsung di `mage.json` atau `~/.mage/mage.json` di bawah kunci `agent`:

```json
{
  "agent": {
    "angular-reviewer": {
      "description": "Review kode Angular menggunakan konvensi tim BCA.",
      "mode": "subagent",
      "model": "merlin/default",
      "temperature": 0.5
    }
  }
}
```

Untuk system prompt-nya, gunakan file markdown di `.mage/agent/` dengan nama yang sama — Mage akan menggabungkan keduanya.

:::tip[Menulis deskripsi yang efektif]
Field `description` adalah kunci delegasi otomatis — model membacanya untuk memutuskan kapan mendelegasikan tugas ke agent ini. Tuliskan kondisi trigger secara eksplisit: *"Gunakan ketika pengguna meminta…"* atau *"Aktifkan sebelum membuat/mengubah X"*. Deskripsi yang samar menghasilkan delegasi yang tidak akurat.
:::
