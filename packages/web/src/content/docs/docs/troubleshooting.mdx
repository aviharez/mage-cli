## `mage: command not found` setelah instalasi

npm menginstal binary global ke direktori yang mungkin tidak ada di `PATH`. Tambahkan direktori npm global ke shell Anda:

```bash
export PATH="$(npm prefix -g)/bin:$PATH"
```

Tambahkan baris ini ke `~/.zshrc` atau `~/.bashrc` agar permanen, lalu restart terminal atau jalankan `source ~/.zshrc`.

Cek lokasi npm global:
```bash
npm prefix -g
```

## Node.js tidak ditemukan atau versi terlalu lama

Mage membutuhkan Node.js **≥ 18**.

```bash
node --version   # cek versi saat ini
```

Jika belum terinstal atau versinya terlalu lama, unduh dari [nodejs.org](https://nodejs.org/en/download).

## Error saat instalasi: registry tidak dapat dijangkau

Pastikan Anda terhubung ke jaringan BCA (langsung atau via VPN) sebelum menjalankan installer. BCA Artifactory (`artifactory.intra.bca.co.id`) hanya dapat diakses dari jaringan internal.

## Error `401 Unauthorized` saat `npm install`

Konfigurasi `~/.npmrc` mungkin rusak atau tidak lengkap. Jalankan ulang installer untuk memperbaiki:

```bash
curl -fsSL https://mage.apps.ocpdevgra.dti.co.id/install | bash
```

Installer bersifat idempoten — aman dijalankan berulang kali. Blok konfigurasi lama di `.npmrc` akan diganti secara otomatis.

Atau periksa isi `~/.npmrc` secara manual dan pastikan ada blok ini:

```
# >>> mage >>>
@mybcabisnis:registry=https://artifactory.intra.bca.co.id/artifactory/api/npm/MBB-Registry-npm/
noproxy[]=artifactory.intra.bca.co.id
always-auth=true
strict-ssl=false
//artifactory.intra.bca.co.id/artifactory/api/npm/MBB-Registry-npm/:_auth=dXNlcm1iYjpCY2FiY2ExMjM=
# <<< mage <<<
```

## Wizard setup tidak muncul

Wizard muncul otomatis hanya jika username udomain belum dikonfigurasi. Untuk menjalankan wizard secara manual:

```bash
mage init
```

## Versi web tidak terbuka (`mage web`)

Pastikan tidak ada proses lain yang menggunakan port yang sama. Coba tentukan port secara eksplisit:

```bash
mage web --port 8080
```

Jika browser tidak terbuka otomatis, buka URL yang dicetak di terminal secara manual.
