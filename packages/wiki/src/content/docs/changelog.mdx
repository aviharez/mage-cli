<ChangelogRelease version="v1.2.11" date="10 Juli 2026" dateTime="2026-07-10" latest>

### Yang baru
- **Dukungan Mac Intel:** Mage kini tersedia untuk Mac dengan prosesor Intel (x64), melengkapi build Apple Silicon (arm64) yang sudah ada. Pengguna Mac Intel dapat menginstal dan menjalankan Mage.
- **New session di window baru:** Saat memulai session baru kini muncul pilihan **This window** (lanjut di jendela ini) atau **New window** (membuka Mage di jendela terminal baru pada direktori yang sama). Fitur window baru hanya didukung di macOS dan Windows; platform lain menampilkan toast error.

### Perbaikan
- **Auto-recovery lebih tangguh:** Error gateway **DPA-115** dan **DPA-117** (gangguan sementara pada gateway/OCP) kini diperlakukan sebagai error retryable dan diulang otomatis oleh policy retry session, bukan langsung ditampilkan sebagai error ke pengguna.

</ChangelogRelease>

<ChangelogRelease version="v1.2.10" date="8 Juli 2026" dateTime="2026-07-08">

### Yang baru
- **`mage skills`:** Perintah CLI baru untuk install/remove skill langsung dari Rune (`mage skills install`, `mage skills remove`).
- **Context gauge di footer:** Persentase context kini ditampilkan di footer prompt (di sebelah hint agent/command), menggantikan panel sidebar lama.

### Perbaikan
- **Akurasi context gauge:** Perhitungan token auto-compaction diselaraskan dengan angka persentase context yang ditampilkan; estimasi pasca-compact disimpan sehingga `/compact` manual ikut memperbarui angka, tidak lagi menampilkan nilai basi.
- **DPA-124 tidak selalu dianggap context overflow:** DPA-124 (error catch-all engine GAIA) sebelumnya selalu dikonversi menjadi context-overflow untuk trigger auto-compaction, padahal juga muncul untuk kegagalan engine lain (mis. 500 generik) yang salah diklasifikasikan. Kini hanya DPA-124 yang `err_debug`-nya menyebut context-length limit yang memicu compaction; sisanya tampil sebagai error biasa.

</ChangelogRelease>

<ChangelogRelease version="v1.2.9" date="3 Juli 2026" dateTime="2026-07-03">

### Yang baru
- **Rename agent:** Seluruh agent dinamai ulang menjadi `build`, `plan`, `explore`, dan `general`.
- **Subagent paralel tanpa batas:** Batas `MAGE_SUBAGENT` dihapus; subagent dan tool call kini berjalan paralel tanpa dibatasi (seperti upstream), mengembalikan throttle yang ditambahkan di v1.2.7.
- **Estimasi token sidebar:** Sidebar menampilkan pemakaian context berdasarkan estimasi token sisi klien, sehingga tetap akurat meski gateway GAIA tidak mengirim data usage.

### Perbaikan
- **Todo list di context tiap turn:** Daftar todo dibaca ulang dari DB dan disuntikkan sebagai system-reminder setiap turn, sehingga model tidak mengulang langkah yang sudah selesai meski melewati batas compaction.
- **Auto-recovery Merlin lebih tangguh:** Beberapa kondisi gateway GAIA kini pulih otomatis, bukan ditampilkan sebagai error ke pengguna:
  - Error **An error occurred while the engine was processing the query** dikonversi ke jalur context-overflow sehingga session otomatis compact lalu lanjut.
  - Jawaban yang hanya mengumumkan aksi (mis. "Let me read the files...") tanpa benar-benar memanggil tool kini disambung otomatis (terbatas beberapa putaran) agar agent tidak berhenti di tengah tugas.
  - Diagnostik gateway yang bersifat sementara (tool result gagal di-parse) diperlakukan sebagai error retryable dan diulang, bukan disalahartikan sebagai overflow.
- **Compaction overflow:** Mengatasi "history too large to compact" dengan membuang byte output tool call lama (dan, bila perlu, turn tertua) sebelum request summarization. Gauge token sidebar juga mengecualikan summary compaction sehingga turun setelah compact.
- **Cache instruksi AGENTS.md:** File instruksi tidak lagi dibaca ulang dari disk pada setiap step (di-cache berdasarkan mtime), mengurangi overhead per turn.

### Performa
- **Kondensasi built-in prompt:** Prompt bawaan `bash`, `todowrite`, dan `qwen` diringkas (~27KB ke ~9KB) tanpa menghapus aturan perilaku/keamanan, untuk memangkas token overhead per turn pada GAIA.

</ChangelogRelease>

<ChangelogRelease version="v1.2.8" date="15 Juni 2026" dateTime="2026-06-15">

### Perbaikan
- **Perbaikan batas context compaction:** Batas context model GAIA dikoreksi dari 262K menjadi 128K sesuai limit aktual gateway. Sebelumnya, compaction tidak pernah terpicu karena threshold dihitung berdasarkan nilai yang terlalu besar, sehingga gateway menolak request ketika prompt mendekati 128K token.

</ChangelogRelease>

<ChangelogRelease version="v1.2.7" date="15 Juni 2026" dateTime="2026-06-15">

### Yang baru
- **Parallel subagent:** Mage kini dapat menjalankan hingga 2 subagent secara bersamaan (sebelumnya hanya 1). Jumlah maksimal dapat dikonfigurasi melalui env var `MAGE_SUBAGENT` (contoh: `MAGE_SUBAGENT=3` untuk 3 parallel, `MAGE_SUBAGENT=1` untuk kembali ke mode serial). Subagent yang melebihi batas akan otomatis mengantri hingga slot tersedia.

</ChangelogRelease>
