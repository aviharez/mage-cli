---
title: MCP Servers
description: Menambahkan tools dari MCP server lokal atau remote ke Mage.
---

Model Context Protocol (MCP) memungkinkan Mage memakai external tools bersama built-in tools. Mage mendukung server lokal dan remote.

:::caution
Setiap MCP tool menambah context. Aktifkan hanya server yang benar-benar dibutuhkan agar context tidak cepat penuh.
:::

## Mengaktifkan MCP

Tambahkan server dengan nama unik pada `mcp` di `~/.mage/mage.json`.

```json title="~/.mage/mage.json"
{
  "mcp": {
    "nama-server": {
      "type": "remote",
      "url": "https://example.com/mcp",
      "enabled": true
    }
  }
}
```

Set `enabled` ke `false` untuk menonaktifkan server tanpa menghapus konfigurasi.

## Server lokal

Gunakan `type: "local"` dan command berbentuk array.

```json title="~/.mage/mage.json"
{
  "mcp": {
    "local-tools": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
      "enabled": true,
      "environment": {
        "MY_ENV_VAR": "value"
      }
    }
  }
}
```

Option server lokal:

| Option | Wajib | Fungsi |
| --- | --- | --- |
| `type` | Ya | Harus `local`. |
| `command` | Ya | Executable dan argument untuk memulai server. |
| `cwd` | Tidak | Working directory process MCP. |
| `environment` | Tidak | Environment variable untuk process. |
| `enabled` | Tidak | Mengaktifkan server saat startup. |
| `timeout` | Tidak | Batas waktu mengambil tools dalam milidetik. |

## Server remote

Gunakan URL MCP dan optional header.

```json title="~/.mage/mage.json"
{
  "mcp": {
    "remote-tools": {
      "type": "remote",
      "url": "https://example.com/mcp",
      "headers": {
        "Authorization": "Bearer {env:MY_API_KEY}"
      }
    }
  }
}
```

Option server remote:

| Option | Wajib | Fungsi |
| --- | --- | --- |
| `type` | Ya | Harus `remote`. |
| `url` | Ya | Endpoint MCP server. |
| `headers` | Tidak | HTTP header tambahan. |
| `oauth` | Tidak | Object konfigurasi OAuth atau `false`. |
| `enabled` | Tidak | Mengaktifkan server saat startup. |
| `timeout` | Tidak | Batas waktu mengambil tools dalam milidetik. |

## OAuth

Mage dapat mendeteksi response `401`, menjalankan OAuth flow, memakai Dynamic Client Registration bila didukung, lalu menyimpan token untuk request berikutnya.

Untuk server OAuth biasa, URL saja sudah cukup.

```json title="~/.mage/mage.json"
{
  "mcp": {
    "oauth-server": {
      "type": "remote",
      "url": "https://example.com/mcp"
    }
  }
}
```

Gunakan credential yang sudah didaftarkan bila provider memberikannya.

```json title="~/.mage/mage.json"
{
  "mcp": {
    "oauth-server": {
      "type": "remote",
      "url": "https://example.com/mcp",
      "oauth": {
        "clientId": "{env:MY_MCP_CLIENT_ID}",
        "clientSecret": "{env:MY_MCP_CLIENT_SECRET}",
        "scope": "tools:read tools:execute"
      }
    }
  }
}
```

Kelola autentikasi melalui CLI.

```bash
mage mcp auth oauth-server
mage mcp list
mage mcp logout oauth-server
mage mcp debug oauth-server
```

Set `oauth: false` bila server memakai API key dan automatic OAuth harus dimatikan.

## Mengelola server

CLI menyediakan flow interaktif untuk menambah dan memasang MCP.

```bash
mage mcp add
mage mcp install
mage mcp remove nama-server
mage mcp list
```

Tool MCP memakai nama server sebagai prefix. Gunakan permission untuk mengontrol server secara global atau per agent.

```json title="~/.mage/mage.json"
{
  "permission": {
    "local-tools_*": "deny"
  },
  "agent": {
    "research": {
      "description": "Riset dokumentasi",
      "permission": {
        "local-tools_*": "allow"
      }
    }
  }
}
```

Pattern `*` cocok dengan seluruh tool milik server tersebut.

## Contoh Context7

```json title="~/.mage/mage.json"
{
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}"
      }
    }
  }
}
```

Sebutkan tool di prompt agar agent memilihnya dengan jelas.

```text
Gunakan context7 untuk mencari dokumentasi API terbaru library ini.
```

Anda juga dapat menambahkan aturan tersebut ke `AGENTS.md` agar berlaku konsisten pada project.
