---

Custom command menyimpan prompt yang dapat dijalankan dari TUI.

```text frame="none"
/test
```

Command ini melengkapi built-in command seperti `/init`, `/undo`, `/redo`, dan `/help`.

## Membuat command file

Simpan Markdown di salah satu lokasi berikut:

- Global: `~/.mage/commands/*.md`
- Project: `.mage/commands/*.md`

```markdown title=".mage/commands/test.md"
---
description: Jalankan test dengan coverage
agent: build
---

Jalankan seluruh test suite dengan coverage.
Tampilkan kegagalan, temukan penyebabnya, lalu usulkan perbaikan minimum.
```

Nama file menjadi nama command. `test.md` dijalankan sebagai `/test`.

## Konfigurasi JSON

Custom command juga dapat didefinisikan di `~/.mage/mage.json`.

```json title="~/.mage/mage.json"
{
  "command": {
    "test": {
      "template": "Jalankan seluruh test suite. Fokus pada test yang gagal dan perbaiki root cause.",
      "description": "Jalankan dan perbaiki test",
      "agent": "build"
    }
  }
}
```

## Template prompt

### Arguments

Gunakan `$ARGUMENTS` untuk seluruh argument atau `$1`, `$2`, dan seterusnya untuk positional argument.

```markdown title=".mage/commands/component.md"
---
description: Buat React component
---

Buat React component bernama $1 di direktori $2.
Gunakan detail tambahan berikut: $ARGUMENTS
```

```text frame="none"
/component Button src/components accessible dan keyboard friendly
```

### Shell output

Gunakan `` !`command` `` untuk memasukkan output shell ke prompt.

```markdown title=".mage/commands/review-changes.md"
---
description: Review perubahan terbaru
---

Perubahan saat ini:
!`git diff --stat`

Review diff lengkap dan laporkan bug atau regression.
```

Command berjalan dari root project dan output-nya menjadi bagian context.

### Referensi file

Gunakan `@path` untuk memasukkan file.

```markdown title=".mage/commands/review-component.md"
---
description: Review component
---

Review @src/components/Button.tsx untuk accessibility dan performance.
```

## Option

- `template`: prompt yang dikirim ke model. Wajib pada konfigurasi JSON.
- `description`: label command di TUI.
- `agent`: agent yang menjalankan command. Default memakai agent aktif.
- `subtask`: paksa command berjalan sebagai child session.

```json title="~/.mage/mage.json"
{
  "command": {
    "analyze": {
      "template": "Analisis $ARGUMENTS dan tulis rekomendasi tanpa mengubah file.",
      "description": "Analisis read-only",
      "agent": "plan",
      "subtask": true
    }
  }
}
```

Custom command dengan nama yang sama akan menggantikan built-in command. Pilih nama yang unik bila override tidak disengaja.
