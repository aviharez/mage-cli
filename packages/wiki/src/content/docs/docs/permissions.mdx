---
title: Permissions
description: Mengontrol action yang diizinkan, meminta persetujuan, atau diblokir.
---

Config `permission` menentukan apakah Mage menjalankan action otomatis, meminta persetujuan, atau menolaknya.

## Action

- `"allow"`: jalankan tanpa approval.
- `"ask"`: minta approval sebelum berjalan.
- `"deny"`: blokir action.

## Auto mode

Flag `--auto` menyetujui permission request yang tidak secara eksplisit diatur sebagai `deny`.

```bash
mage --auto
mage run --auto "Refactor module ini"
```

Rule `deny` tetap berlaku. Auto mode dapat diaktifkan atau dimatikan dari command palette TUI.

## Konfigurasi

Atur default global dan override tool tertentu di `~/.mage/mage.json`.

```json title="~/.mage/mage.json"
{
  "permission": {
    "*": "ask",
    "read": "allow",
    "edit": "ask",
    "bash": "ask"
  }
}
```

Seluruh permission juga dapat diatur sekaligus.

```json title="~/.mage/mage.json"
{
  "permission": "allow"
}
```

## Rule granular

Gunakan object untuk membedakan action berdasarkan input tool.

```json title="~/.mage/mage.json"
{
  "permission": {
    "bash": {
      "*": "ask",
      "git status *": "allow",
      "git diff *": "allow",
      "git push *": "deny",
      "rm *": "deny"
    },
    "edit": {
      "*": "deny",
      "packages/wiki/src/content/**/*.mdx": "allow"
    }
  }
}
```

Rule dibaca berurutan dan kecocokan terakhir menang. Letakkan catch-all `*` lebih dulu, kemudian rule spesifik.

### Wildcard

- `*` cocok dengan nol atau lebih karakter.
- `?` cocok dengan tepat satu karakter.
- Karakter lain dicocokkan secara literal.

### Home directory

Pola dapat diawali `~` atau `$HOME`.

```text
~/projects/*
$HOME/projects/*
```

### External directory

Path di luar working directory tetap memerlukan `external_directory`, walaupun ditulis dengan `~`.

```json title="~/.mage/mage.json"
{
  "permission": {
    "external_directory": {
      "~/projects/reference/**": "allow"
    },
    "edit": {
      "~/projects/reference/**": "deny"
    }
  }
}
```

Contoh tersebut mengizinkan access ke reference project, tetapi melarang edit.

## Permission yang tersedia

| Key | Melindungi |
| --- | --- |
| `read` | Membaca file. |
| `edit` | Menulis, mengedit, dan menerapkan patch. |
| `glob` | Mencari path dengan glob. |
| `grep` | Mencari content. |
| `bash` | Menjalankan shell command. |
| `task` | Memanggil subagent. |
| `skill` | Memuat Agent Skill. |
| `question` | Meminta input pengguna. |
| `external_directory` | Mengakses path di luar workspace. |
| `doom_loop` | Mengulang tool call identik beberapa kali. |

## Default

Sebagian besar permission default adalah `allow`. `external_directory` dan `doom_loop` default ke `ask`. File `.env` ditolak secara default, kecuali contoh seperti `.env.example`.

```json title="~/.mage/mage.json"
{
  "permission": {
    "read": {
      "*": "allow",
      "*.env": "deny",
      "*.env.*": "deny",
      "*.env.example": "allow"
    }
  }
}
```

## Saat Mage meminta approval

TUI menawarkan tiga hasil:

- `once`: izinkan request ini saja.
- `always`: izinkan pola yang disarankan selama sesi aktif.
- `reject`: tolak request.

Untuk shell command, pola `always` biasanya berupa command prefix yang aman, misalnya `git status *`.

## Override per agent

Permission agent digabungkan dengan config global dan rule agent mengambil prioritas.

```json title="~/.mage/mage.json"
{
  "permission": {
    "bash": "ask"
  },
  "agent": {
    "review": {
      "description": "Review read-only",
      "mode": "subagent",
      "permission": {
        "edit": "deny",
        "bash": {
          "*": "deny",
          "git diff *": "allow"
        }
      }
    }
  }
}
```
