Theme mengatur warna TUI Mage tanpa mengubah perilaku agent.

## Kebutuhan terminal

Untuk hasil terbaik, gunakan terminal dengan true color support dan pastikan `COLORTERM=truecolor` tersedia. Theme dapat memakai warna eksplisit atau mewarisi warna terminal.

## Built-in themes

Buka theme picker melalui command berikut:

```text frame="none"
/themes
```

Pilihan disimpan untuk sesi berikutnya. Mage juga menyediakan theme `system` yang mengikuti warna terminal.

## Menggunakan theme

Theme dapat dipilih dari command palette atau melalui `~/.mage/tui.json`.

```json title="~/.mage/tui.json"
{
  "theme": "mage"
}
```

## Custom theme

Simpan file JSON theme pada salah satu lokasi berikut:

- Global: `~/.mage/themes/*.json`
- Project: `.mage/themes/*.json`

Theme project mengambil prioritas atas theme global dengan nama yang sama.

```json title="~/.mage/themes/fokus.json"
{
  "$schema": "https://mage.ai/theme.json",
  "defs": {
    "accent": "#8d6bc5",
    "surface": {
      "dark": "#131116",
      "light": "#fcfbfd"
    }
  },
  "theme": {
    "primary": "accent",
    "secondary": "accent",
    "background": "transparent",
    "backgroundPanel": "surface",
    "text": {
      "dark": "#eeeaf2",
      "light": "#1d1922"
    },
    "textMuted": {
      "dark": "#aaa3b2",
      "light": "#5f5867"
    },
    "border": {
      "dark": "#41384c",
      "light": "#bbb0c7"
    },
    "diffAdded": "#6ee7b7",
    "diffRemoved": "#f87171",
    "warning": "#fbbf24",
    "error": "#f87171"
  }
}
```

## Format warna

Nilai warna dapat berbentuk:

- Hex seperti `#8d6bc5`
- ANSI index `0` sampai `255`
- Reference ke key di `defs`
- Object `{ "dark": "...", "light": "..." }`
- `"transparent"` untuk memakai background terminal

Gunakan token semantic seperti `primary`, `text`, `textMuted`, `background`, `border`, `diffAdded`, `diffRemoved`, `warning`, dan `error`. Pastikan kontras tetap terbaca pada light dan dark terminal.

## Urutan pencarian

Mage mencari theme dari built-in theme, global directory, lalu project directory. File yang ditemukan terakhir dengan nama sama akan menggantikan definisi sebelumnya.

Setelah menambah atau mengubah file theme, buka kembali `/themes` dan pilih theme tersebut.
