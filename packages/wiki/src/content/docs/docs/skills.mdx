---

Agent Skills adalah paket instruksi reusable yang disimpan dalam `SKILL.md`. Mage menampilkan nama dan description skill kepada agent, lalu memuat isi lengkapnya hanya ketika relevan.

## Lokasi file

Buat satu folder per skill dan letakkan `SKILL.md` di dalamnya.

- Project Mage: `.mage/skills/<nama>/SKILL.md`
- Global Mage: `~/.mage/skills/<nama>/SKILL.md`

Untuk project-local skill, Mage berjalan naik dari current directory sampai root Git worktree dan menemukan skill pada setiap scope yang sesuai.

## Frontmatter

Setiap `SKILL.md` harus diawali YAML frontmatter.

- `name`: wajib.
- `description`: wajib.
- `metadata`: opsional, map string ke string.

Field lain diabaikan.

## Aturan nama

Nama skill harus:

- Panjang 1 sampai 64 karakter.
- Menggunakan huruf kecil, angka, dan satu hyphen sebagai pemisah.
- Tidak diawali atau diakhiri hyphen.
- Tidak memiliki dua hyphen berurutan.
- Sama dengan nama direktori skill.

```text
^[a-z0-9]+(-[a-z0-9]+)*$
```

Description harus memiliki panjang 1 sampai 1024 karakter dan menjelaskan dengan spesifik kapan skill dipakai.

## Contoh

```markdown title=".mage/skills/api-documentation/SKILL.md"
---
name: api-documentation
description: Generate clear API documentation from source changes
metadata:
  audience: developers
  workflow: documentation
---

## What it does

- Extract endpoints and parameters from source changes
- Keep request and response examples up to date
- Flag breaking changes for review

## When to use

Use when documenting a new or changed API.
Ask for the target documentation format when unspecified.
```

## Cara discovery bekerja

Agent melihat katalog ringkas berisi `name` dan `description`. Saat skill dipilih, tool `skill` memuat isi `SKILL.md` ke context. Karena itu, description harus membedakan skill dari skill lain tanpa memasukkan seluruh workflow.

## Permission skill

Kontrol akses skill melalui pattern di `~/.mage/mage.json`.

```json title="~/.mage/mage.json"
{
  "permission": {
    "skill": {
      "*": "allow",
      "internal-*": "deny",
      "experimental-*": "ask"
    }
  }
}
```

| Action | Perilaku |
| --- | --- |
| `allow` | Skill dimuat langsung. |
| `ask` | Mage meminta approval. |
| `deny` | Skill disembunyikan dan tidak dapat dimuat. |

Agent kustom dapat memiliki override sendiri.

```markdown title="~/.mage/agents/docs.md"
---
description: Menulis dokumentasi
mode: subagent
permission:
  skill:
    "documents-*": allow
---

Tulis dokumentasi yang jelas dan teruji.
```

## Menonaktifkan skill

Blokir seluruh skill tool pada agent tertentu dengan permission.

```json title="~/.mage/mage.json"
{
  "agent": {
    "restricted": {
      "description": "Agent tanpa external instruction",
      "permission": {
        "skill": "deny"
      }
    }
  }
}
```

## Troubleshooting

Jika skill tidak muncul:

1. Pastikan nama file tepat `SKILL.md`.
2. Pastikan `name` dan `description` tersedia.
3. Cocokkan `name` dengan nama direktori.
4. Pastikan nama unik pada seluruh lokasi discovery.
5. Periksa apakah permission mengatur skill ke `deny`.
6. Jalankan `mage skills` untuk melihat command pengelolaan yang tersedia.
