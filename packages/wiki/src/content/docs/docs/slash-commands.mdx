Slash command diketikkan di input TUI, diawali dengan `/`. Autocomplete muncul otomatis saat Anda mengetik.

---

## Sesi

| Command | Alias | Deskripsi |
|---------|-------|-----------|
| `/new` | `/clear` | Mulai sesi baru |
| `/sessions` | `/resume`, `/continue` | Ganti atau lanjutkan sesi yang ada |
| `/rename` | - | Ganti nama sesi saat ini |
| `/fork` | - | Buat sesi baru dari titik tertentu di timeline |
| `/timeline` | - | Lompat ke pesan tertentu / buka dialog timeline |
| `/compact` | `/summarize` | Kompres/ringkas riwayat sesi untuk menghemat konteks |
| `/undo` | - | Batalkan pesan user terakhir dan kembalikan ke state sebelumnya |
| `/redo` | - | Ulangi aksi yang baru dibatalkan (tersedia jika ada revert) |
| `/copy` | - | Salin seluruh transkrip sesi ke clipboard |
| `/export` | - | Ekspor transkrip sesi ke file `.md` atau buka di `$EDITOR` |
| `/timestamps` | `/toggle-timestamps` | Tampilkan/sembunyikan timestamp pada setiap pesan |

---

## Sistem & Agen

| Command | Alias | Deskripsi |
|---------|-------|-----------|
| `/agents` | - | Ganti agen yang aktif |
| `/mcps` | - | Aktifkan/nonaktifkan MCP server |
| `/themes` | - | Ganti tema tampilan TUI |
| `/status` | - | Tampilkan dialog status sesi |
| `/help` | - | Tampilkan daftar shortcut dan bantuan |
| `/exit` | `/quit`, `/q` | Keluar dari Mage |

---

## Prompt & Editor

| Command | Deskripsi |
|---------|-----------|
| `/editor` | Buka `$EDITOR` eksternal untuk menulis prompt yang panjang |
| `/skills` | Buka dialog browser skill - lihat skill yang tersedia dan aktifkan secara manual |

---

## Perintah server

| Command | Deskripsi |
|---------|-----------|
| `/init` | Jalankan wizard setup `AGENTS.md` untuk proyek saat ini - panduan membuat file konteks agen |

---

:::note[Alias]
Beberapa command memiliki alias yang setara. Misalnya `/sessions`, `/resume`, dan `/continue` menjalankan aksi yang sama. Gunakan yang paling nyaman untuk Anda.
:::

:::tip[Skill via /skills]
Normalnya skill terpicu otomatis dari prompt natural language Anda. Gunakan `/skills` jika ingin memilih skill secara manual. Lihat [Skill](/docs/skills) untuk detail.
:::
